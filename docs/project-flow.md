# Career Compass AI Flow

## Student Flow
Landing -> Signup/Login -> Dashboard -> Profile Setup -> Interests -> Skills -> Assessment Summary -> Generate Recommendations -> Career Detail -> Roadmap -> Learning Resources -> Chatbot -> Saved Careers

## Admin Flow
Admin Login -> Admin Dashboard -> Manage Users -> Manage Careers -> Manage Roadmaps -> Manage Resources -> Reports

## Backend Flow
React -> Firebase Auth -> Firebase ID Token -> FastAPI Token Verification -> PostgreSQL -> Recommendation/Resource/Chatbot Services -> JSON Response

## Recommendation Formula
Academic Match: 20%  
Interest Match: 30%  
Skill Match: 30%  
Subject Match: 20%
